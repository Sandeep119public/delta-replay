# Local replay datasets

This directory is the canonical local store for Binance historical replay datasets.

Parquet files are generated by the Binance dataset downloader and are intentionally ignored by Git. Replay reads these immutable files through the data API; replay never downloads missing candles from Binance.

Use the downloader CLI:

python backend/scripts/download_binance_dataset.py --symbol SOLUSDT --timeframe 15m --start 2026-01-01T00:00:00Z --end 2026-02-01T00:00:00Z

Set DATASET_DIR to place datasets somewhere else on the machine.
